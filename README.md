# UX Persona Generator

A front end concept for a tool that turns quick inputs into structured UX personas. Originally designed in Figma as a personal project, then partially built using HTML, CSS, Bootstrap, and JavaScript.

## Purpose

The idea is to let a designer fill in a short form (name, gender, age range, occupation, design purpose, experience level, tech level) and generate a clear, structured persona card in seconds, useful for early-stage UX work or learning.

## Status

This repo currently contains the static front end only. The layout and form are built, but the persona generation logic isn't implemented yet, so submitting the form doesn't produce output at this stage.

## Pages

- `index.html`: landing page introducing the tool
- `form.html`: input form for persona details

## Built with

- Figma (original design)
- HTML, CSS, Bootstrap, JavaScript (front end)
